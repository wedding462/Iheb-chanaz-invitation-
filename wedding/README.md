# Iheb & Chanaz — Invitation de mariage

Site d’invitation responsive en français, avec une ouverture interactive en touchant la lune, des animations d’apparition, une navigation vers les détails et un bouton pour revenir à la lune.

## Fichiers inclus
- `index.html` — contenu de l’invitation en français
- `styles.css` — design responsive, ciel étoilé, animations et lune gibbeuse croissante
- `script.js` — interactions tactiles/clic, défilement, animations et rejouer
- `assets/moon.svg` — icône SVG de lune gibbeuse croissante
- `README.md` — instructions

## Ouvrir le site
Ouvrez simplement `index.html` dans un navigateur moderne. Aucune compilation n’est nécessaire. Google Fonts et le lien Google Maps utilisent Internet.

## Publier le site
Téléversez le contenu de ce dossier vers un hébergement statique (GitHub Pages, Netlify ou votre hébergeur). Conservez le dossier `assets` à côté du fichier HTML.
